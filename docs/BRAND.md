# ⩒Yeutika — identidad visual

El logotipo se articula alrededor de una V central:

- superior izquierda: reloj — tiempo y sesiones;
- superior derecha: matriz 4×5 — cuatro semanas lectivas y lunes-viernes;
- inferior izquierda: escuadra — estructura y planificación;
- inferior derecha: check — validación y auditoría.

## Colores
- Azul principal: #062050
- Azul secundario: #0D3972
- Verde ⩒Yeutika: #59B411
- Fondo: #F6F8FB
- Superficie: #FFFFFF
- Texto: #122038

## Principios
Interfaz profesional, clara, accesible y orientada a equipos directivos. El verde indica progreso o validación, pero nunca es la única señal.
